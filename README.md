# VINATA HCNS HUB (web)

Trang tĩnh chỉ chứa mã chương trình của VINATA HCNS HUB. Không chứa dữ liệu nhân sự.
Dữ liệu: SharePoint `ADM-HR/Shared Documents/HCNS-BACKUP/VINATA-HCNS-HUB-state.json` (tải về sau khi đăng nhập Microsoft 365).

Hosting: GitHub Pages, custom domain `www.hub.vinata.com.vn` (file CNAME).
Cấu hình Entra: chạy `Register-HCNS-HubApp.ps1 -HubUrl https://www.hub.vinata.com.vn/` rồi thay `__TENANT_ID__` / `__CLIENT_ID__` trong index.html (script tự sinh bản .configured.html - đổi tên thành index.html).
